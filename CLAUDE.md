# Code Skills

Claude Code plugin containing engineering skills for developer workflows.

## Before making changes

Read and follow `CONTRIBUTING.md` — it covers skill structure, commit conventions, and the review checklist.

## Modifying skills

Skills are behaviour-shaping code, not documentation. Changing wording, structure, or examples in a SKILL.md can alter how Claude behaves in ways that are hard to predict by reading the diff. If a skill has evals (`evals/evals.json`), run them before and after your change to confirm the skill still works — or works better.

## Writing new skills

Read at least two existing SKILL.md files before drafting a new one. Match the style, depth, and structure you find — don't invent new conventions.
